# 汇丰级银行支付系统 完整架构模块（标准金融四层架构）
整体分层：**接入网关层 → 交易业务层 → 核心账务清算层 → 基础合规运维层**

## 一、渠道接入网关层（统一入口、对外所有流量）
所有客户端、第三方、外联机构全部走这一层，**金融级限流、防刷、报文解析、路由**
1. **线上渠道网关模块**
   - 手机银行支付网关
   - 网上银行支付网关
   - 小程序/APP快捷支付网关
2. **线下渠道网关模块**
   - POS收单网关
   - ATM转账/取款网关
   - 柜台柜面支付接口
3. **外联合作网关模块**
   - 银联对接网关
   - 网联对接网关
   - 第三方支付对接（支付宝/微信）前置
4. **国际跨境网关模块（汇丰核心）**
   - SWIFT报文收发模块
   - 跨境清算前置
   - 境外合作银行对接网关
5. **通用网关能力**
   - 协议适配（HTTP/HTTPS/ISO8583/SWIFT/FSB）
   - 流量控制、熔断、降级、黑白名单
   - 请求验签、防重放、幂等校验
   - 统一日志、统一跟踪ID

## 二、支付交易核心业务层（所有交易逻辑）
### 1. 支付交易引擎模块（核心中的核心）
- 统一交易编排引擎
- 正向交易：转账、消费、充值、缴费、代扣、代付
- 逆向交易：退款、冲正、撤销、挂账、补账
- 交易幂等、状态机管理、分布式事务补偿
- 多币种交易支持（港币、美元、人民币、欧元等）

### 2. 商户收单模块（B端）
- 商户入驻、资质审核
- 商户费率配置、阶梯费率
- 商户交易限额、风控等级
- 商户对账文件生成
- 商户资金冻结/解冻

### 3. 个人支付模块（C端）
- 个人账户支付权限
- 快捷支付签约/解约
- 单笔/单日限额管控
- 支付密码、短信、生物识别校验

### 4. 批量代付/代扣模块（企业常用）
- 批量发薪
- 批量代扣费用
- 批量文件导入交易
- 批量交易分批、失败重试、结果回传

### 5. 跨境支付模块（汇丰最强特色）
- 跨境汇入、汇出
- 结售汇（外币兑换）
- 跨境手续费、中转行费用计算
- 跨境申报、国别风险控制
- SWIFT MT103/MT202 报文生成解析

## 三、资金与账务清算核心层（银行和互联网支付最大区别）
### 1. 全行统一账务模块（核心金融资产）
- 分户账管理（客户账、内部账、机构账、手续费账）
- 复式记账（金融强制）
- 实时入账/挂账/暂收暂付
- 账务平衡校验、日终轧账

### 2. 清算中心模块
- 人行大额、小额、超级网银清算对接
- 银联清算、网联清算
- 跨境SWIFT清算
- 行内跨账户清算
- 清算批次管理、清算状态流转

### 3. 资金结算模块
- T+0 / T+1 / D+N 结算配置
- 商户结算、企业结算、跨境结算
- 手续费、罚息、汇率差结算
- 备付金管理（银行合规必备）

### 4. 对账中心模块（金融零差错）
- 渠道对账（银联/网联/SWIFT）
- 行内账务对账
- 商户对账
- 长短款差错处理
- 对账差异自动修复、人工复核

## 四、风控与反洗钱合规层（汇丰最重、监管最强）
### 1. 实时风控引擎
- 交易风险评分
- 异地、异设备、大额、深夜风控
- 交易频次限流、速度风控
- 黑白名单、敏感商户、敏感账户拦截

### 2. AML反洗钱模块（银行强制）
- 大额交易监控
- 可疑交易识别
- 分层次客户风险等级
- 交易穿透分析
- 洗钱、恐怖融资、制裁名单筛查（OFAC）

### 3. KYC客户合规模块
- 个人/企业实名核验
- 客户准入、禁入名单
- 证件有效期、客户等级管理
- 尽职调查记录

### 4. 监管报送模块
- 人行支付监管报送
- 反洗钱监管报送
- 跨境外汇监管报送
- 审计留痕、合规台账

## 五、用户、账户、权限体系模块
1. **客户账户管理模块**
   - 借记卡、信用卡、对公账户
   - 账户状态：正常、冻结、挂失、止付
2. **签约协议模块**
   - 快捷支付协议
   - 代扣协议
   - 自动续费协议
3. **权限与操作员模块**
   - 行员权限、分级审批
   - 大额交易复核、双人审批
   - 操作日志全审计

## 六、费率、计费、优惠模块
1. **手续费计费引擎**
   - 转账手续费、跨境手续费
   - 商户收单费率
   - 阶梯计费、优惠减免
2. **营销支付模块**
   - 立减、折扣、补贴
   - 支付红包、优惠券抵扣
   - 计费冲抵、台账核销

## 七、数据、报表、运维支撑模块
1. **交易日志与审计模块**
2. **支付数据统计报表**
3. **日终批处理模块**
   - 日终轧账
   - 批量清算
   - 批量对账
   - 批量归档
4. **系统监控告警模块**
5. **参数配置中心**
   - 费率、限额、风控阈值、渠道参数统一配置

# 最终整体架构层级（可直接画架构图）
1. **渠道接入层**（网关、外联、报文）
2. **交易业务层**（支付、退款、代收代付、跨境）
3. **资金核心层**（账务、清算、结算、对账）
4. **风控合规层**（风控、AML、KYC、监管报送）
5. **支撑平台层**（用户、权限、计费、运维、批处理）

# 和普通互联网支付系统的核心差异（汇丰银行必备）
1. 必须**复式记账、金融账务**，不是简单流水
2. 必须**完整央行/银联/网联/SWIFT外联**
3. 必须**强AML反洗钱、OFAC制裁筛查**
4. 必须**多币种、跨境清算、结售汇**
5. 必须**监管报送、强审计、不可篡改日志**
6. 必须**日终轧账、总分平衡、金融级一致性**
