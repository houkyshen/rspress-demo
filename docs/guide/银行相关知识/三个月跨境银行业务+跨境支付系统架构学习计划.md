# 三个月跨境银行业务+跨境支付系统架构学习计划
定位：汇丰银行软件架构师
目标：吃透跨境清算业务、SWIFT/ISO20022报文、同业账务、支付中台架构，能够独立做跨境支付系统设计、MT→MX迁移方案设计。
前置条件：Java基础、微服务架构基础；每周投入15～20小时（工作日每晚2h + 周末全天）。

整体分三阶段：
- 第1个月：夯实国际结算+外汇清算业务（纯业务，无大量编码）
- 第2个月：精通SWIFT MT / ISO20022 MX报文 + 动手编码解析报文
- 第3个月：搭建完整跨境系统架构模型，吃透路由、头寸、对账、合规四大模块，并完成原型设计

---

## 第一月：业务筑基（第1～4周）
核心目标：彻底搞懂跨境资金流转链路，消除“业务盲区”，看懂代理行、Nostro/Vostro、起息日、头寸、清算网络整套规则。

### 第1周：跨境业务全景 + 账户体系
学习内容：
1. 书籍：《国际结算》苏宗祥 前3章
2. 业务知识点：
   - 对公/零售跨境汇款业务分类：T/T、L/C、托收
   - Nostro（我行在他行）、Vostro（他行在我行）、Loro账户定义
   - NRA、OSA、离岸账户区别；CNY在岸 / CNH离岸人民币
   - 代理行模式、Cover头寸偿付、Book Transfer行内转账
3. 清算网络梳理：
   SWIFT、SWIFT gpi、CIPS、CHIPS、Fedwire、SEPA、HKCHATS 各自适用币种与场景
4. 作业：手绘一笔跨境美元电汇完整资金链路（客户付款→报文下发→头寸划拨→收款行入账）

### 第2周：外汇业务 + 资金头寸管理
学习内容：
1. 结售汇、个人年度便利化额度、国际收支BOP申报规则
2. Value Date起息日、Cut-off截单时间、多时区+多国家节假日日历规则
3. 外币头寸、预存头寸（Pre-funding）、资金透支管控
4. 集团跨境资金池、Global Pooling轧差清算业务
资料：银行外汇业务实务手册 + 外管局收支申报指引
作业：
梳理不同清算系统截单时间，总结“报文发送日≠起息日”的业务规则。

### 第3周：贸易结算业务（信用证+托收）
学习内容：
1. L/C开立MT700、修改MT707、单据议付流程
2. D/P付款交单、D/A承兑交单业务流程
3. Incoterms 贸易术语与单证校验逻辑
配套：CDCS基础课程精简内容
作业：区分电汇业务与信用证业务在系统上的不同模块划分。

### 第4周：跨境监管与合规（汇丰重中之重）
学习内容：
1. AML、KYC、交易尽职调查
2. OFAC、联合国制裁名单筛查规则
3. 大额交易CTR、可疑交易STR上报
4. 跨境报文50场（汇款人）、59场（收款人）字段审查要求
输出成果（第一月收尾）：
1. 完整业务流程图：普通电汇、行内转账、带头寸偿付的代理行付款
2. 账户领域模型文档：Nostro分户账、客户外汇账户模型
3. 整理一份业务规则清单：起息日、节假日、截单、头寸风控规则

---

## 第二月：报文标准 + 编码实战（第5～8周）
核心目标：吃透MT报文与ISO20022 MX报文，熟练使用Prowide开源库做报文序列化、字段解析、MT/MX互转，掌握STP直通处理规则。

### 第5周：SWIFT MT报文体系
1. 研读内容：
   - MT103（客户汇款）字段详解（50,52,56,57,59场）
   - MT202、MT202COV（银行头寸调拨）
   - MT700信用证基础报文
2. 文档：SWIFT官方MT报文手册
3. 实操：
   用Prowide-Core Java库：
   - 构建MT103报文
   - 解析报文字段
   - 报文校验、BIC/IBAN校验

### 第6周：SWIFT gpi + CIPS业务报文
1. gpi追踪字段、UETR唯一交易号规则
2. CIPS系统参与者架构、人民币跨境报文规范
3. 同业对账报文 camt.054
作业：编写代码提取gpi追踪字段。

### 第7周：ISO 20022 MX 报文标准（汇丰改造核心）
重点报文：
- pacs.008：跨境客户支付（对应MT103）
- pacs.009：同业头寸划拨（对应MT202）
- camt.053/camt.054：对账单与交易回执
学习：XSD结构、XML报文结构
实操：使用prowide-iso20022生成与解析MX报文。

### 第8周：MT报文 ↔ MX报文双向转换 + STP处理
1. 梳理字段映射关系：MT103 对应 pacs.008
2. 设计自动路由：自动识别报文类型、自动校验字段
3. 异常场景：字段缺失、字符不规范、报文被退回
本月交付物：
1. 可运行Java工程：Prowide实现MT构造、MX生成、双向转换
2. 报文字段映射文档（MT→ISO20022）
3. 整理报文异常退回场景清单（业务异常+格式异常）

GitHub重点使用仓库：
- prowide/prowide-core
- prowide/prowide-iso20022

## 第三月：系统架构设计 + 模块落地（第9～12周）
核心目标：搭建汇丰级跨境支付中台整体架构，拆分各个子系统，完成领域建模、路由引擎、账务、对账、合规模块设计。

### 第9周：整体架构分层设计
学习参考：
Apache Fineract 核心银行账务架构、全球支付Hub架构
拆分七层架构：
1. 接入层：SWIFT Alliance网关、CIPS前置
2. 报文转换层：MT/MX解析、格式校验
3. 路由服务层：清算通道智能选择引擎
4. 交易核心层：跨境付款引擎、起息日计算服务
5. 账务层：Nostro分户账、多币种总账、头寸扣划
6. 对账层：代理行对账单自动匹配
7. 合规与监管报送层：制裁筛查、BOP申报、反洗钱监控

作业：画出整体架构图，并明确各模块之间接口。

### 第10周：核心业务模块深度设计
逐个攻克架构难点（外资行跨境系统核心痛点）：
1. 多时区+多国家节假日日历服务（独立公共微服务）
2. 起息日自动计算组件
3. 多通道路由策略：
   优先级：行内Book Transfer > SWIFT gpi > CIPS人民币 > 普通代理行
4. Nostro同业账户账务模型：付款扣头寸、来账入头寸

### 第11周：对账引擎 + 外汇结售汇子系统
1. 自动对账引擎：银行对账单camt.054与本地交易流水自动勾兑
2. 未达账项处理、差错冲正流程
3. 结售汇牌价接口、CNY/CNH分账处理逻辑

### 第12周：合规模块 + 项目方案输出（最终交付）
1. 制裁筛查服务架构：全字段黑名单拦截（收款人、付款行、国家）
2. 大额/可疑交易采集、国际收支申报报文生成
3. 输出正式方案文档：
   - 《跨境支付中台总体架构方案》
   - 《MT向ISO20022迁移技术方案》
   - 领域ER图：交易、报文、账户、头寸、清算路由实体模型
