# 搞懂 Agent 形态演进的底层逻辑！Claw 并不一定是 OpenClaw

## 从大模型到 Agent：被“懒人”推着走的演进
让我们先快速捋一下 Claw 的来历。在并不遥远的过去——其实就是三年前，人们还在使用一问一答的传统方式与大模型聊天。一开始大家觉得挺方便，但很快麻烦的人类就开始嫌麻烦了。比如改个代码，要在对话框里复制粘贴好几遍，连 Ctrl-C 和 Ctrl-V 都不想按了。于是，人们在中间加了个智能体（Agent）来完成这些复杂操作，懒惰的人类终于又开心了起来。

大模型的智商很难再有突破性的提升，于是人们开始往智能体上不断叠加能力。对于大多数普通人来说，更多还是按感官形态来区分的：以命令行形式存在的 Claw Code、CodeX、iFlow 等；以编程 IDE 形式存在的 Cursor；以及以桌面助手/客户端形式存在的 Claw 客户端和 CodeX 客户端等等。显然，桌面助手的形态更容易传播和使用。

## Agent 为什么还是不够“人”？Claw 的出现
剥离掉具体形态来看，Agent 仍然是个躺在电脑里、只能被动接收你一问一答的“死板”程序。与此同时，普通人对于“Agent 到底哪里像智能体了”的多年困惑，也一直没有得到解答。这时 OpenClaw 出现了。它的本质其实就是在 Agent 上增加了连接社交软件、定时任务、记忆系统等更加人性化的功能而已，内核依旧是 Agent。

当然，后面这几个功能虽然设计上很有深度，但很可惜，普通人看不到。反倒是一个最稀松平常的“连接社交软件”的功能，让它彻底火出了圈。你仔细看那张图——其实只不过是聊天入口换了个位置，但这却第一次让更多人感受到 Agent 像个活生生的人了。于是，在原本 Agent 的基础上增加功能，使其更接近私人助手这样一个层级的东西，现在就被叫做 **Claw**。这个词暂时还没有官方明确定义，但我比较喜欢把它理解成“可闹”——就是可以跟它唠嗑了。

## 从 Claw 看出生态趋势：一切 Agent 都将“Claw 化”
好，那再往上会是什么？我知道你很急，但你先别急。现在你能根据逻辑推理，来预测一下接下来会发生的生态变化吗？你想想，你细想：右边是社交软件，你看看现在还有哪个老大哥没支持？眼镜自然就是趋势之一了。不过今天我们把重点放在左边。左边是进化版的 Agent，现在还只有 OpenClaw 一个人，以及一堆还没有进化成 Claw 形态的 Agent——最重要的体现就是，还不能通过社交软件的入口来触发。

这就很简单了：原本的这些 Agent 产品进化或推出 Claw 形态，已然是必然趋势。比如 Claw Code 增加了 remote control 功能，可以在手机端调控电脑上的 Claw Code。CodeX 现在还没发生什么变化，可以观察一段时间，正好验证一下预言。腾讯在 Claw Code 之外推出了个新产品叫 **WorkBody**，面向专门助手的同时，还能非常方便地接入各种社交软件——这其实就是个 Claw 形态。虽然大家在形式上可能有细微差异，但这块版图的补充是必然的，完全可以通过逻辑推演出来。大家也可以在弹幕中分享一下，你在看这期视频时又有哪些传统的 Agent 进化成 Claw 了？或者干脆来个大胆的预测，过几天我们一起看看你猜得准不准。

## 大厂的 Claw 产品怎么用？WorkBody 实测
由于 OpenClaw 还是面向开发者和极客朋友多一些，即使很多厂商提供了一键部署方案，但最终它仍是一个开源的、偏开发者向的产品。所以大厂下来专门做成熟的 Claw 产品，就解决了这些痛点。比如腾讯的 WorkBody 搭配飞书，两端都是非常直观的软件应用，这必然会成为趋势。

这种应用程序形态对普通人来说友好多了。你只需要打开应用，然后选择 Claw 设置。我这里集成的是飞书，所以点击配置，把飞书机器人的 APP ID 和 Secret Key 粘贴进去，再把回调地址复制回飞书的机器人平台。飞书端的配置，无论哪种 Claw 设置都是一样的。如果不会，可以点击配置指南，或者去网上搜索教程，完全通用。

配置好后，你就可以在飞书上操控这台电脑中的 WorkBody 了。比如我先简单问一句：“你是谁？”发送后，电脑端可以实时看到他确实问了“你是谁”，然后用同样的语言回复了我。你看，我当前的工作空间中已经有很多文件了，那是我之前玩出来的结果。现在我让他清空一下：“把当前工作空间中的所有文件都删除。”发过去后，大部分文件都成功删除了，只是在删除一个目录时，他提示这是一个危险动作，需要我手动确认。当然，如果你特别放心，也可以改成不需要每次都询问。

以上的功能其实和一个普通 Agent 差不多，但它更方便的地方在于，比如我在外面，想回家时就能看到它给我准备好的各种文档，保存在本地电脑里。那我就可以这样说：“你帮我上网搜索最近的关于 openclaw 小龙虾的各种资料，最终整理成一份 PDF 报告、一份 HTML 格式的报告，还有一份 PPT 格式的报告，都保存到我的本地。”然后你看，他在我的本地真的帮我整理出了这些格式的报告，比如这份 PDF，确实是一份非常精美的报告。

一些小的任务也可以交给它。比如我说：“我之后可能会做一期关于各种语言基础语法的视频，现在你帮我写十种常用语言的 Hello World，然后保存到本地。”完美完成任务！他确实在我的本地成功生成了十种语言的 Hello World，这样我回到家之后就可以直接使用这些文件进行视频创作了。

目前 WorkBody 还有三大福利：所有 CodeBody 国内版用户直接送五千个 Credits，新老用户都有；还能免费领取腾讯云轻量服务器资源；还有百万 Credits 悬赏活动，发布 Claw 实战内容就有机会获得。感兴趣的朋友一定要在近期玩一下哦。

## 闲聊几句：从 Agent 到 Claw，再到未来系统
最后的几分钟，我想对着那张图闲聊几句，这部分就不写稿子了，想到哪儿说到哪儿。

整个趋势其实非常清晰。别看中间过程中出现了各种各样的产品，最早形态只有大模型，就是 ChatGPT 刚出来的时候，那时我们只能对着网页跟它聊天。后来，比如豆包的出现，丰富了手机端的应用，网页端本身也有了各种优化，比如增加了 Markdown 格式、回复标题更友好等等——这就是在大模型这个形态上不断更人性化的优化方式。但这一块卷到头以后，人们发现只能聊天是远远不够的，于是就有了 Agent。

一开始 Agent 的形态更多还是面向开发者，比如就是一个命令行，对普通人很不友好；或者一个编程 IDE，专门针对编程的程序员。所以最初大家推出的哪怕是桌面助手，也都叫什么什么 Code，比如 CodeBody 或者 Claw Code，还只是面向编程的。后来发现，他完全可以作为一个通用助手：不但能编程，还能删除文件、做 PDF 报告、操作本地文件夹、发送邮件等等。这就是在向通用智能体去演进，也是一个桌面形态上的变化。

但人们后来又发现，智能体这个东西，不论你在形式上做多少创新，它最终还是让人感觉是一个死板的程序，依然面向开发者更多一些，这个圈层还是没有打开。所以，Claw 形态就出现了。

我们现在就处在 Claw 这个阶段的内部。模仿大模型和智能体的演进过程你就会发现，Claw 这个形态在内部又经历了同样的转换思路。从一开始的 OpenClaw，很多操作都是面向程序员的，所以现在这个阶段，必然就是各个大厂都把自己的 Agent 弄成 Claw 形态的东西——这就是我们刚刚那张图左边部分的进化。再有就是接入社交软件这一块，因为一开始这是国外的东西，只能接入国外的一些常用社交软件，国内的飞书、钉钉、QQ 甚至微信，肯定也会越来越多地接入，这必然也是一个趋势。到这个时候，Claw 这一层的形态基本上又被大家卷到头了。

那再往上的形态会是什么呢？这个我也不知道了，但我自己有一个大胆的猜测：再往上，应该是我们的操作系统，或者说我们各式各样的系统，向 Claw 所需要的部分去靠拢。每个电脑中可能都会有“龙虾”，那么操作系统会不会也向着更适合 Agent 居住的环境而进化？这其实就是 AgentOS 这个词的含义。最终可能倒逼着整个操作系统对 Agent 做出一些改造。而在下一个阶段，当整个系统也进化成了一个智能系统之后，再往上可能就是系统与系统之间的互联——或许就是全球的智能系统都连接起来了，就会出现我们电影中描绘的场景，比如《机械公敌》或者《黑镜》里面那些非常遥远的未来才能达到的、世界范围的影响。这就是我的一点点思考。
