# 银行跨境业务学习路线
## 一、整体学习路线（适配汇丰软件架构师，业务→清算→报文→系统架构→合规，分4阶段）
### 阶段1：夯实银行业务基础（2～3周，先把业务流程吃透，避免只懂代码不懂业务）
目标：搞懂跨境交易全链路、账户体系、清算路径、起息/头寸/代理行模式。
1. 核心业务模块
   - 零售跨境电汇；对公T/T、信用证、托收
   - Nostro/Vostro同业账户、NRA/OSA、CNY/CNH
   - 代理行清算、Cover头寸、Book Transfer行内转账
   - 起息日、截单时间、多币种头寸管理
2. 必须吃透清算网络：SWIFT、SWIFT gpi、CIPS、CHIPS、Fedwire、SEPA、HKCHATS
3. 外汇业务：结售汇、即期FX、跨境资金池、FDI/ODI资本项目
4. 合规：国际收支BOP申报、AML/KYC、OFAC制裁筛查

### 阶段2：精通报文标准（SWIFT MT + ISO20022 MX，汇丰当下核心改造项目，3～4周）
目标：读懂报文字段、掌握MT↔MX互转、理解STP直通处理。
重点报文：MT103、MT202 COV、MT700、camt.054、pacs.008、pain系列。

### 阶段3：系统架构与IT流程（4周，对接汇丰全球支付中台）
目标：拆解跨境支付系统分层：报文网关→路由引擎→交易核心→账务（Nostro分户账）→对账→合规筛查→监管报送。
掌握：报文路由、时区节假日引擎、头寸管控、自动对账、MT/MX双协议网关设计。

### 阶段4：合规+项目实战（长期）
制裁名单引擎、交易监控、大额/可疑交易报送，结合开源代码做报文解析、路由模拟。

## 二、权威书籍（分业务实务、清算报文、IT架构、外汇合规四类）
### （A）银行业务实务（必读，银行国际业务权威教材）
1. **《国际结算（第八版）苏宗祥、徐捷》（中国金融出版社）【首选】**
CDCS跟单信用证专家考试指定教材，完整覆盖电汇、信用证、托收、代理行往来、SWIFT业务流程，对公跨境结算圣经，非常贴合汇丰国际业务场景。



2. **《国际结算实务与案例》徐进亮**
大量真实银行案例，讲解跨境收付、贸易结算、单据审核，适合IT人员理解业务异常场景。



3. **《国际贸易融资 实务与案例》**
覆盖押汇、福费廷、跨境资金池、集团全球资金归集，对应汇丰Global Pooling业务。

4. **《外汇业务实务》银行同业版**
讲解结售汇、多币种账务、Nostro账户头寸管理、在岸/离岸人民币（CNY/CNH）分账。

### （B）SWIFT & ISO20022 报文专业书籍（架构改造必备）
1. *SWIFT Messaging Handbook*（SWIFT官方手册，MT报文字段权威依据）
2. *ISO 20022 for Payments*（SWIFT官方MX报文标准文档）
3. 《SWIFT报文解析与跨境支付系统开发实战》（国内金融IT实战书）
4. 《跨境人民币清算与CIPS系统实务》，讲解CIPS报文与参与者架构。

### （C）银行核心系统&支付架构书籍
1. 《银行核心系统架构设计》
讲解多币种账务、分户账、总账、头寸模块，Nostro同业账户账务模型。
2. 《全球支付清算系统：SWIFT、CHIPS、CIPS架构与实务》
把全球各大清算网络的技术链路讲透，非常适合汇丰全球多通道路由设计。
3. 《金融报文系统ISO20022迁移实战》
MT报文向MX报文迁移方案，汇丰全行正在推进的改造项目。

### （D）反洗钱与跨境合规（汇丰全球强管控域）
1. 《银行跨境业务反洗钱与制裁合规实务》
OFAC名单筛查、交易监控、跨境报文字段尽职调查（50场/59场收款人审查）。
2. 外汇管理局《国际收支统计申报业务指引》，BOP申报业务规则。

## 三、GitHub开源仓库（分三大类：报文解析库、跨境支付系统原型、核心银行账务）
### 第一类：SWIFT MT / ISO20022 MX 报文处理（开发首选，工业级库）
#### 1）Prowide 【Java，银行广泛商用，开源核心库】⭐最高优先级
项目地址：
- MT报文：github.com/prowide/prowide-core
- ISO20022 MX报文：github.com/prowide/prowide-iso20022
能力：
- 完整MT103/MT202字段模型、报文序列化/反序列化
- MT与XML/JSON互转、BIC/IBAN合法性校验
- 支持SWIFT gpi字段解析；提供JPA持久化实体
汇丰及国内外绝大多数大行的报文工具都是基于这套二次开发，非常贴合你的技术栈。

#### 2）Python 报文工具（快速测试、脚本调试）
- swift-iso20022-toolbox：可视化XML报文解析工具（Streamlit页面）
- iso20022-gen：自动生成MX报文XSD与实体代码

#### 3）Rust / Go 高性能版本（新一代网关选型参考）
github.com/rabbittrix/swift-rs-core （SWIFT MT+ISO20022解析）

### 第二类：跨境支付系统原型（用来学习整体业务架构）
1. **Apache Fineract（开源核心银行系统）⭐必读架构**
github.com/apache/fineract
- 多币种账户、复式记账、分户账、往来账户模型
- 可以从中学习Nostro同业账户、跨境付款账务处理逻辑
全球几百家银行在用，账务架构高度接近传统外资行核心。

2. crossBorderFundsTransfer
github.com/Archstrategy/crossBorderFundsTransfer
跨境多银行代理行支付流程演示，包含代理行头寸、多币种交割流程，适合梳理SWIFT清算链路。

3. IBM World Wire 开源版
IBM开源的全球跨境支付网络，包含清算路由、FX兑换、多方对账模型，对标汇丰Global Payments Hub设计思路。

### 第三类：辅助子系统（对账、路由、合规）
1. 支付路由引擎开源实现：payment-routing-service
学习多通道自动择优（行内转账>SWIFT gpi>CIPS>普通代理行）
2. 银行自动对账框架：reconciliation-engine
Nostro账户对账单与交易流水自动匹配，跨境系统必备模块。

### 第四类：CIPS人民币跨境报文开源解析工具
GitHub搜索关键词：`CIPS pacs.008 camt.054 parser`，可以找到国内银行开源的CIPS MX报文解析Demo。

## 五、分阶段实操计划（架构师落地练习）
1. **业务阶段**
画出一笔美元跨境电汇完整链路：客户付款→本行扣账→生成MT103→MT202头寸偿付→代理行Nostro扣账→收款行入账，区分Cover Payment与Book Transfer。

2. **报文阶段**
用Prowide库编写代码：构造MT103报文，解析字段50（汇款人）、59（收款人），再转换为MX pacs.008报文，完成MT↔MX互转。

3. **系统架构阶段**
基于Fineract账务模型，画出跨境系统分层架构：
报文网关 → 路由服务 → 交易引擎 → Nostro分户账 → 对账服务 → 合规筛查 → 监管报送。

4. **进阶模拟**
搭建简易路由引擎，自动判断：同一汇丰分支机构走行内转账；美元走CHIPS；人民币优先走CIPS。

## 六、补充避坑提醒
1. 不要一上来只啃代码，跨境系统80%的bug来自业务规则：起息日、节假日时区、截单时间、头寸透支规则、BOP申报字段。
2. 开源项目仅用来学习架构与报文解析，SWIFT正式接入必须使用银行合规网关（如Alliance Gateway），开源库只能做后台应用层解析。
3. 汇丰多币种、多时区、全球分行互联，重点吃透：多日历引擎、分行头寸集中管控、集团内部轧差清算。
