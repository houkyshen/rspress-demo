# 银行跨境业务知识点
# 一、银行跨境交易核心业务全景（面向汇丰全球银行IT架构场景）
跨境交易分为两大主线：**零售跨境汇款** + **对公跨境结算（贸易金融+资本项目）**，汇丰作为全球性清算行，同时覆盖SWIFT清算、本地清算网络、离岸人民币、跨境资金池、CIPS、海外分行直连清算。

## 1. 主要业务品类
### （1）零售跨境业务
- 电汇（T/T）境外汇出/汇入
- 外币现汇、现钞买卖
- 跨境个人外汇（年度便利化额度）
- 跨境理财通（粤港澳）

### （2）对公跨境业务（汇丰核心对公IT域）
1. 国际结算：电汇T/T、信用证L/C、托收D/P、D/A
2. 贸易融资：出口押汇、进口押汇、福费廷、保理
3. 跨境资本业务：FDI、ODI、外债登记、跨境双向人民币资金池、外债专户、NRA账户
4. 跨境清算：同业清算、头寸调拨、清算行代理清算

### （3）底层清算通道（架构设计必须落地）
1. **SWIFT**：跨境主流报文通道（MT报文、新版ISO 20022 MX报文）
2. **CIPS**：人民币跨境支付系统（离岸+在岸人民币跨境）
3. 区域本地清算：CHAPS（英国）、Fedwire/CHIPS（美国美元）、EURO1/SEPA（欧元区）、HKCHATS（香港港元/美元/人民币清算）
4. 行内跨境：汇丰全球分行内部转账（Book Transfer，行内轧差，不经过外部清算网络）

# 二、架构师必须掌握的核心专业术语（分5大类：清算报文、资金头寸、外汇合规、账户体系、风控监管）

## 第一类：报文与清算术语（IT系统改造、SWIFT升级、ISO20022迁移高频词）
1. **SWIFT**
环球银行金融电信协会，跨境报文传输网络，仅传递指令，不完成资金交割。
2. **MT Message**
传统SWIFT报文：MT103（客户汇款）、MT202（银行同业头寸调拨）、MT700（信用证开立），汇丰全球遗留系统大量MT报文。
3. **ISO 20022 / MX Message**
新一代标准化报文，全球银行强制切换，CIPS、SWIFT gpi均采用MX，是汇丰下一代跨境核心系统改造重点。
4. **SWIFT gpi**
全球支付创新，支持跨境交易全程追踪、手续费透明、到账时效可视，目前主流跨境电汇都走gpi通道。
5. **CHIPS**
纽约清算所银行同业支付系统：美元跨境同业清算（离岸美元主流通道）。
6. **Fedwire**
美国美联储美元实时大额清算（在岸美元）。
7. **CIPS**
人民币跨境支付系统，分一期、二期，支持跨境人民币实时清算，分直接参与者、间接参与者。
8. **Correspondent Bank（代理行）**
账户行，汇丰海外分行之间互相开立同业账户，依托代理行完成跨行间资金划转。
9. **Cover Payment（头寸偿付）**
头寸补付。MT103是客户指令，MT202 COV用来完成资金头寸交割。
10. **Book Transfer（行内转账）**
同一银行不同分支机构间转账，只更新内部分户账，不走外部清算网络，零清算费用、实时到账。
11. **STP Straight Through Processing**
直通式处理，无人工干预，报文自动解析、自动入账、自动头寸扣划，跨境核心系统首要架构目标。
12. **Reconciliation（清算对账）**
代理行账户对账、清算网络回单对账、头寸流水对账，跨境系统必备对账子系统。

## 第二类：账户体系术语（核心账务架构设计）
1. **NRA账户**
境外机构境内外汇账户，境外企业在汇丰中国开立外币账户，不纳入外汇额度管理。
2. **OSA账户**
离岸账户，早期离岸账户体系，目前国内主要保留NRA。
3. **CA（Correspondent Account）同业往来账户**
本行开在境外代理行的账户（往账账户）；Vostro Account（来账账户）：境外银行开在汇丰的同业账户。
    - Nostro：我行在他行账户（我行往账）
    - Vostro：他行在我行账户（来账）
    - Loro：第三方账户
4. **CNH 离岸人民币**
香港、新加坡等境外离岸人民币；CNY 在岸人民币。跨境交易区分CNY/CNH两套牌价与清算通道。
5. **跨境双向人民币资金池**
跨国集团境内外成员企业之间归集人民币资金，属于资本项目跨境业务，需要额度备案。

## 第三类：外汇与资金头寸术语（资金系统+总账系统对接）
1. **FX Spot 即期外汇**
成交后T+2交割的外币买卖，跨境汇款配套结售汇大多为即期。
2. **结汇 / 购汇**
结汇：外币→人民币；购汇：人民币→外币。
3. **头寸 Position**
银行外币资金余额。跨境付出汇款会消耗外币头寸，系统需要实时管控头寸敞口。
4. **Pre-funding 预存头寸**
在代理行账户预先存入资金，保证对外付款不会透支。
5. **Value Date 起息日**
资金正式交割生效的日期，跨境交易起息日不等于报文发送日，受时区、清算系统截止时间影响，是账务引擎关键字段。
6. **Cut-off Time 截单时间**
各清算系统每日受理报文截止时点，超过则顺延下一工作日起息，系统需要时区日历+节假日日历引擎。
7. **FX Swap 外汇掉期**
短期调剂外币头寸，对公跨境资金业务常用工具。

## 第四类：国际结算贸易金融术语（对公跨境业务模块）
1. **T/T Telegraphic Transfer**
电汇，最普遍跨境付款。
2. **L/C Letter of Credit 信用证**
银行信用付款，MT7系列报文，分为即期信用证、远期信用证。
3. **D/P 付款交单、D/A 承兑交单**
跟单托收业务。
4. **Incoterms 国际贸易术语**
FOB、CIF、CFR，贸易单证校验规则。
5. **BPO 银行付款承诺**
基于贸易数据元的电子化信用证，贸易金融数字化改造方向。

## 第五类：合规、反洗钱与监管（汇丰全球合规体系是架构重中之重）
### 监管与合规术语（跨境交易IT风控模块核心）
1. **FATF 反洗钱金融行动特别工作组**
全球跨境反洗钱规则制定组织。
2. **OFAC 美国制裁名单**
美国财政部特别指定国民清单，所有美元跨境交易必须做名单筛查，汇丰全球反洗钱（AML）系统第一道拦截规则。
3. **UN Sanction List 联合国制裁名单**
跨境报文必筛查黑名单。
4. **AML 反洗钱；KYC 了解你的客户**
跨境汇款强制做客户尽职调查，大额、可疑交易上报。
5. **STR 可疑交易报告、CTR 大额交易报告**
国内外汇监管报送报文，对接外汇局（SAFE）系统。
6. **反制裁筛查（Sanction Screening）**
对付款人、收款人、开户行、国家地区做全字段筛查，是汇丰跨境支付系统必不可少的中间件模块。
7. **跨境外汇收支申报**
所有对公跨境收支需要向外汇管理局做国际收支申报（BOP申报），零售额度内免申报。
8. **MT103 Field 50/59**
汇款人、收款人字段，反洗钱筛查的核心字段，也是SWIFT gpi追踪字段。
9. **高风险国家（High Jurisdiction）**
FATF灰名单、黑名单国家，交易自动强化尽调，系统路由管控。

## 第六类：汇丰全球化特有的业务术语（分行IT互联场景）
1. **HSBC Global Pooling 全球资金归集**
跨国集团多币种资金池，多分行自动轧差清算。
2. **Global Payments Hub 全球支付中枢**
汇丰统一跨境支付中台，集中处理全球各分行跨境报文路由、头寸调度。
3. **Multi-currency Nostro 多币种同业账户**
一账户多币种，简化代理行账务架构。
4. **Intra-group Settlement 集团内轧差清算**
降低SWIFT报文量，减少清算手续费与合规审查。

# 三、面向软件架构师的关键系统域划分（汇丰IT架构现状）
1. 报文网关：SWIFT网关、CIPS前置、ISO20022报文转换引擎（MT↔MX互转）
2. 支付核心：跨境付款交易引擎、起息日计算、路由引擎（自动选择SWIFT/gpi、CIPS、本地清算、行内转账）
3. 账务子系统：Nostro/Vostro分户账、多币种总账、头寸管控
4. 对账平台：代理行对账单自动匹配、清算流水对账
5. 合规中台：名单筛查引擎（OFAC+UN+本地黑名单）、KYC接口、交易监控、大额/可疑报送
6. 外汇子系统：结售汇牌价、外汇敞口管理、CNY/CNH分账处理
7. 监管报送：国际收支BOP申报、外汇局数据上报、人行跨境人民币报送

# 四、补充架构痛点（汇丰同业普遍面临的改造方向）
1. MT报文全面迁移至ISO 20022 MX报文，SWIFT与CIPS双协议兼容；
2. 构建统一跨境支付路由中台，自动择优选择清算通道，降低代理行成本；
3. 全行统一多时区节假日日历、起息日计算服务；
4. 把制裁筛查从零散接口改造为独立全局合规微服务；
5. 零售+对公跨境业务中台化，剥离账务与报文网关，实现业务复用。
